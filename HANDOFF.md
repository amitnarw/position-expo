## 3. Critical setup notes (do not undo)

### NativeWind 5 RC requires a lightningcss pin

`package.json` must keep:

```json
"overrides": {
  "lightningcss": "1.30.1"
}
```

Without it Metro fails with:

```
Error: failed to deserialize; expected an object-like struct named Specifier, found ()
```

### Runtime CSS variables

- Token values live in **two** places that must stay in sync:
  - `src/theme/tokens.ts` → injected at runtime by `ThemeProvider` via `VariableContextProvider`.
  - `src/global.css` → compile-time fallbacks and Tailwind theme definitions.
- `metro.config.js` excludes the dynamic `--color-*` variables from static inlining. If colors stop switching at runtime, check this first.
- Skia cannot read CSS variables; use `useTheme().colors` for anything drawn on canvas. `src/lib/color.ts` has `mixHex`, `withAlpha`, `luminance`.

### Typed routes

`app.json` has `experiments.typedRoutes: true`. `.expo/types` is regenerated by `expo start` / `expo export`. `tsc` is currently clean; if route-string errors appear after adding routes, run `npx expo start` once to regenerate.

## 4. Architecture

### Routes

```
src/app/
├── _layout.tsx              Root stack, fonts, splash, hydration gate, Stack.Protected
├── index.tsx                Pure redirect gate: /age → /onboarding → /today
├── age.tsx                  18+ gate (outside protected app group)
├── onboarding.tsx            3-step intent/comfort flow
├── (tabs)/
│   ├── _layout.tsx           JS Tabs + custom floating pill bar
│   ├── today.tsx             Hero plate, greeting, return row, 4-plate grid, collections, guide
│   ├── atlas.tsx             Search entry, pace/effort filters, 2-col grid of all 36
│   ├── learn.tsx             8 guides + 6 collections
│   └── saved.tsx             Favourites grid + history
├── plate/[slug].tsx          Plate detail (modal)
├── guide/[slug].tsx          Guide detail (modal)
├── collection/[slug].tsx     Collection detail (modal)
├── search.tsx                Search modal
└── settings.tsx              Settings modal
```

Protection model:

- `!ageVerified` → only `age` is available.
- `ageVerified && !onboarded` → only `onboarding`.
- `ageVerified && onboarded` → `(tabs)` + all modals.
- `index` is always registered and redirects with `<Redirect />`.

Modal screens render their own headers (`headerShown: false` globally).

### Tab bar

`src/components/nav/floating-tab-bar.tsx` is a custom `BottomTabBarProps` implementation. Important API detail for this expo-router build: the props expose **`emitter` + `navigateToTab(routeKey)`**, not `navigation`:

```tsx
emitter.emit({ type: 'tabPress', target: route.key, canPreventDefault: true });
navigateToTab(route.key);
```

The bar is **in-flow, not absolute** (transparent wrapper + paper pill), so screens do not need extra bottom padding for it.

### Art engine

```
src/art/
├── body.ts        Figure model, Catmull-Rom spline, tapered ribbons, halo pass, framing
├── poses/a.ts     Plates 1–12
├── poses/b.ts     Plates 13–24
├── poses/c.ts     Plates 25–36
├── poses.ts       Merge of a/b/c
└── scene.ts       Skia path cache (getArt, hasArt, poseIds)
src/components/art/pose-art.tsx   <PoseArt pose size animate mono ground />
```

How it works:

- A figure is **centre lines only** (`head`, `shoulders`, `chest?`, `hip`, up to two arms and two legs).
- Limbs are tapered ribbons; the root is tucked inside the torso and the start cap is omitted (`ribbonPath(..., capStart=false)`).
- Each body is painted back-to-front with a widened **paper halo** that knocks out whatever sits behind it. Front figure = ink; back figure = clay mixed toward paper.
- A pose is auto-fitted into a 1000×1000 square by `poseToScene` with a per-pose `padding`.
- `PoseArt` renders hairlines at a near-constant ~1.4pt on screen and supports a slow breathing drift (respects reduced motion).

**Art language:** fine-line contour plates on bone paper. Solid silhouettes were tried and rejected — they read as blobs.

QA loop:

```bash
npx tsx scripts/preview-poses.mjs
```

Writes `design/pose-sheet-outline-{1,2,3}.png` (12 plates per sheet) plus per-plate outline/tint/solid renders. This is the only visual QA that has been done — **not verified on a device**.

Known weak plates:

- `the-shell` — the nested curled bodies still read a little ambiguous at large size (the folded leg can look like a beak). It is the weakest plate. Fine at thumbnail size.
- `the-hush`, `the-anchor` were re-authored and now read clearly.
- Any pose can be tuned by editing its centre lines in `src/art/poses/*.ts` and re-running the preview script. No renderer changes needed.

### Stores

- Both expose `hydrated` and `markHydrated()`; the root layout waits for both before rendering the stack.

### Theme

- `src/theme/tokens.ts` — light/dark palettes + `cssVariablesFor()`.
- `src/theme/ThemeProvider.tsx` — resolves `system|light|dark`, injects CSS variables, sets `Appearance` and system background.
- Accent editions: `clay` (default), `sage`, `plum`, `ochre`.
- Type tokens are defined in `src/global.css`: `text-display/title/headline/subtitle/body/small/caption/label/numeric`; fonts are Fraunces (display) + Geist (UI), loaded per weight in `src/theme/fonts.ts`.

### UI primitives

Shared content components:

- `src/components/plates/plate-card.tsx` — `PlateCard` (square grid card) and `PlateRow` (compact row).
- `src/components/content/modal-header.tsx` — shared modal top bar.

### 6.4 Known risks to check first

1. **NativeWind class conflicts** — `AppText` already sets font/size classes; adding conflicting `font-*` or `text-*` in a `className` may not override deterministically. The navigation agent avoided stacking these; audit any new text.
2. **Tab bar API** — if the tab bar throws on press, confirm the installed expo-router still exposes `emitter` + `navigateToTab` (see §4).
3. **Runtime theme variables** — if accent/theme changes do nothing, re-check the `metro.config.js` variable-exclusion list and that `tokens.ts` / `global.css` keys match.
4. **`max-w-[…ch]`** is silently dropped by react-native-css. Use px only (this was already fixed in the placeholder).
5. **Modal + root protection** — resetting the age gate from Settings flips `ageVerified` to false while inside a protected modal. The navigator should auto-redirect to `index` → `/age`; verify there is no crash on the way out.
6. **Hydration flash** — the root hides the stack until both stores hydrate. If a screen ever appears before hydration on a cold start, the guard in `_layout.tsx` is the place to fix it.

### 6.5 Fixed in the verification pass

- **Plate bodies painted the wrong ground.** `PoseArt` filled each figure with `colors.paper`, but every plate is mounted on a `bg-surface` card, so each body would have shown as a visible paper-coloured blob (much more obvious in dark mode). The default ground is now `colors.surface`; pass `ground` explicitly if a plate is ever mounted on a different background.
- **Collection preview overflowed narrow screens.** Three fixed 96 px plates (304 px + gaps) overflowed a 320 px phone. They are now `flex-1` squares.
- **Collection membership drifted.** 29 positions claimed collections that did not list them back. `collections.ts` is now the single source of truth; `scripts/reconcile-collections.mjs` rewrites each position's `collections` array to match, and `scripts/check-content.mjs` fails the build if they diverge again. Three plates (`threshold`, `the-compass`, `the-anchor`) were added to Foundations / Close & quiet / Strength & trust so that every plate belongs to at least one path.
- **Lint configured.** `eslint.config.js` (flat) + `eslint`/`eslint-config-expo` dev dependencies; the codebase is clean.
- **Onboarding step wrapper** no longer forces `flex: 1` inside a ScrollView, which could clip tall steps on small phones.

## 7. Design system reference

### Palette (light)

| Token | Hex |
|---|---|
| paper | `#F7F2EA` |
| surface | `#FFFBF4` |
| surface2 | `#EFE6D9` |
| ink | `#171310` |
| inkSoft | `#3D352F` |
| muted | `#8A7F74` |
| line | `#E3DACB` |
| clay / accent | `#B25E45` |
| claySoft | `#E9C9BB` |
| sage | `#6F7A62` |
| plum | `#6D4A5D` |
| ochre | `#B0813F` |
| danger | `#A33A2E` |

Dark equivalents live in `src/theme/tokens.ts`.

### Type scale

`display 60/62`, `title 40/44`, `headline 28/34`, `subtitle 20/28`, `body 16/25`, `small 14/21`, `caption 12/16`, `label 11/14`, `numeric 13/16`. Display, title, headline and quotes use Fraunces; the rest use Geist.

### Rules of the visual language

- Bone paper, ink, one clay accent. No gradients. Hairlines instead of shadows.
- Generous margins; editorial asymmetry; serif numerals; sentence case.
- Plates are always framed as paper objects (hairline border, `rounded-card`).
- No explicit imagery, ever — only abstract contour plates.
- Motion is slow and subtle; every animation respects reduced motion.
